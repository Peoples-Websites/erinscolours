# Commission: WorkWise for Screen

November, 2025

<div>

  <b>Read <a href="https://www.leeds-art.ac.uk/whats-happening/leeds-arts-university-news/workwise-for-screen-commission-textile-design-graduate" target="_blank">Leeds Arts University's article</a> about the commission.</b>

  <a href="https://www.leeds-art.ac.uk/whats-happening/leeds-arts-university-news/workwise-for-screen-commission-textile-design-graduate" target="_blank"><img src="/pics/2025/workwise-article.png" width="250" height="200" /></a>

</div>

<div>
  <a href="https://www.workwiseforscreen.org.uk/en" target="_blank">Workwise for Screen</a> is a £1.5m pilot programme created with support from the BFI and National Lottery funding, which supports screen businesses and employers in prioritising equality, dignity and respect in the workplace.
</div>
